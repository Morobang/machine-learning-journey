# Regression - Teaching Module

This folder contains comprehensive teaching material for the `01_supervised_learning/01_regression` notebooks.

## Purpose
- Keep notebooks compact with step-by-step code and minimal markdown
- Provide detailed explanations, diagrams, and theory in dedicated teaching files
- Explain complex concepts in simple, easy-to-understand terms

## How to Use
- **Notebooks**: Contain concise overviews and step-by-step implementation
- **Teaching files**: Provide deep-dive explanations with examples and diagrams
- **Cross-references**: Notebooks link to relevant teaching materials

## Algorithm-Specific Guides
- `01_simple_linear_regression.md` - Complete guide to Simple Linear Regression ✅
- `02_multiple_linear_regression.md` - Using multiple features for better predictions ✅
- `03_polynomial_regression.md` - Capturing curved relationships with polynomials ✅
- `04_support_vector_regression.md` - SVR for complex non-linear regression ✅
- `05_decision_tree_regression.md` - Tree-based regression with interpretable decisions ✅
- `06_random_forest_regression.md` - Ensemble regression for robust predictions ✅

## General Concepts
- `missing_values.md` - Handling missing data
- `encoding.md` - Categorical encoding strategies
- `scaling.md` - Feature scaling decisions
- `feature_engineering.md` - Feature creation and selection
- `diagrams.md` - Visual explanations and diagrams

## Teaching Approach
Each algorithm guide includes:
- **Simple explanations** using real-world analogies
- **Mathematical foundations** explained in intuitive terms
- **Visual diagrams** to illustrate concepts
- **Practical examples** with step-by-step calculations
- **When to use** and when to avoid each method
- **Common pitfalls** and how to avoid them
- **Real-world applications** across different domains
