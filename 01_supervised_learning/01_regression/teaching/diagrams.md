# Diagrams & Visual Teaching Aids

Suggested diagrams to include when teaching regression:
- Train/Test split visualization (features in red, target in blue)
- Residual plots (predicted vs residuals)
- Line plot showing fitted regression line vs actual points
- Feature distribution before/after scaling

Format:
- Keep diagrams in markdown as images (store under `teaching/images/` if created)
- Notebooks will reference these diagrams when appropriate
