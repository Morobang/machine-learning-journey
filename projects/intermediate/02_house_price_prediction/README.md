**Difficulty:** Intermediate
**Status:** Planned
**Estimated time:** 6–8 hours

---

## The Business Problem

A real-estate platform wants to show buyers an estimated fair price for any listed property.
The estimate has to be **accurate enough to be useful** (within ~10% of actual sale price) and **explainable** (buyers want to understand why a house is priced the way it is).

This is the most common end-to-end ML project in data science interviews.
It tests feature engineering, handling skewed distributions, ensembling, and model interpretation all in one.

---

## Dataset

**Source:** [Kaggle — House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
**Rows:** 1,460 training samples
**Features:** 79 explanatory variables (mix of numeric and categorical)
**Target:** `SalePrice` (in USD)

The dataset is intentionally messy:
- 19 features with missing values (some missing >80% of rows)
- Mix of ordinal, nominal, and numeric features
- Target is right-skewed — log-transformation usually helps

## Key Challenges (and How to Approach Them)

| Challenge | Approach |
|-----------|----------|
| 19 features with NaN | Distinguish structural NaN (no garage → `GarageType=None`) from random missing data |
| 79 features — which matter? | Feature importance from Random Forest + correlation with target |
| Right-skewed `SalePrice` | `np.log1p(y)` before training, `np.expm1(y_pred)` after |
| Many categorical columns | Ordinal encode quality columns (Poor→Fair→Good→Excellent), one-hot the rest |
| Evaluation metric | Kaggle uses RMSLE — use `np.log1p` on target to make it equivalent to RMSE |

## Suggested Approach

### Notebook 01 — EDA and Data Quality
1. Load train.csv, check shape
2. Plot `SalePrice` distribution — show the skew, show log-transform effect
3. Map out missing values: which features, how many, what do they mean?
4. Correlation with `SalePrice` — top 10 most correlated features
5. Plot scatter plots of top numeric features vs `SalePrice`
6. Plot box plots of top categorical features vs `SalePrice`

### Notebook 02 — Feature Engineering
1. Fill structural NaNs (e.g. `GarageType` NaN → `"None"`)
2. Fill random NaNs (numeric → median, categorical → mode)
3. Ordinal encode quality features: `{"Po":1,"Fa":2,"TA":3,"Gd":4,"Ex":5}`
4. One-hot encode remaining categoricals
5. Create 2–3 new features (e.g. `TotalSF = TotalBsmtSF + 1stFlrSF + 2ndFlrSF`)
6. Log-transform `SalePrice`

### Notebook 03 — Modelling
1. Ridge Regression baseline (linear model, fast to train)
2. Random Forest Regressor
3. XGBoost with cross-validation
4. Simple average ensemble of best two models
5. SHAP summary plot
6. Generate `submission.csv` and submit to Kaggle
